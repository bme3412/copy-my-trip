# Paris overview artwork sourcing ledger

Reviewed 12 October 2026. This is an artwork review, not a change to catalog identity or publication approval. Six requested records were researched. **No new commercial artwork is approved in this pass.** All six use intentional typography. Existing original photography and licensed place/person photographs keep their credits; unaffected books keep their existing cover behavior.

The shared work-ID manifest is `app/src/lib/culture/artwork.ts`. Pending entries carry no image URL. An approved entry must supply a local asset, alt text, identity, source, credit, permission evidence and restrictions. `WorkArtwork` is shared by cards and details, contains the whole image and falls back to the existing presentation on load failure. Audio remains square. Asset credits are plain text so artwork inside a detail link never nests another link.

## Applying a future approval

Keep the same work ID. Record the exact edition/recording or show identity; approved file; rights holder/creator credit; written or published permission URL; allowed placements, crops and expiry if any. Store the original approval evidence in the editorial area. Add a local asset beneath `/culture/artwork/`, set the manifest entry to approved, and run overview/culture tests plus a visual check in both cards and details. Permission for one image does not approve the other five.
